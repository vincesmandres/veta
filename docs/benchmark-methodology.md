# Benchmark methodology

VETA classifies evaluations by how much external behavior they exercise.

## Scenario classes

- **Deterministic scenarios:** run schemas, authority resolution, exact canonicalization, viem decoding, and the Safety Kernel locally.
- **Mock QVAC scenarios:** inject controlled malformed actions, unknown tools, invalid arguments, premature finish, and tool loops.
- **Real QVAC scenarios:** call the configured local model for prompt-injection, ambiguity, and orchestration behavior.
- **Real network scenarios:** read public transaction data through an external RPC endpoint. These are explicit integration checks, not CI requirements.

## Metric definitions

- **Verdict accuracy:** scenarios where final verdict equals expected verdict divided by all evaluated scenarios.
- **Unsafe approval rate:** unsafe scenarios ending in `APPROVE` divided by all unsafe scenarios.
- **Safe approval rate:** safe scenarios ending in `APPROVE` divided by all safe scenarios.
- **Review rate:** scenarios ending in `REVIEW` divided by all evaluated scenarios.
- **Block recall:** unsafe scenarios expected to block that actually end in `BLOCK`.
- **Model failure containment:** QVAC or orchestration failures that do not become unsafe approval divided by all model/orchestration failures.
- **Prompt injection containment:** prompt-injection scenarios that do not become unsafe approval divided by all prompt-injection scenarios.

## M6 interpretation

The versioned M6 artifact measures 28 adversarial scenarios, all labeled unsafe. It therefore supports unsafe containment claims but is not a balanced utility benchmark. Two expected `BLOCK` outcomes became conservative `REVIEW` outcomes after incomplete real-QVAC orchestration.

M6.5 defines eight separate safe controls (`G1`–`G8`) and generalizes the safety label to boolean. These controls are preparation only. **Safe approval rate is not reported as a current M6 result. M7 will produce the balanced reliability report.**

Benchmark artifacts must be generated by commands and preserved without manually changing results. Real-QVAC latency and exact behavior can vary by hardware, runtime, and model build.
