# Benchmark artifacts

This directory stores machine-readable evidence generated by VETA benchmark commands. Files are intentionally versioned for hackathon reproducibility and must not contain credentials or private data.

## Files

- `m6-adversarial-results.json`: generated by `npm run veta:m6`; contains the M6 dataset version, scenario definitions, per-run traces, metrics, and failure categories.
- `m4-reliability.json`: generated by `npm run veta:m4:benchmark`; records real local-QVAC orchestration reliability when that benchmark is run.

## Execution classes

- `DETERMINISTIC`: local schemas, authority resolution, EVM decoding, and Safety Kernel behavior. These should be stable across machines.
- `MOCK_QVAC`: controlled malformed actions and tool failures used to test fail-closed orchestration.
- `REAL_QVAC`: calls the configured local QVAC runtime. Output and latency may vary by model, runtime version, and hardware.
- Live RPC validation is documented separately in `docs/reality-check.md`; it is not required by CI.

Artifacts must be regenerated by their commands rather than edited to improve results. GitHub CI does not regenerate real-QVAC artifacts.
